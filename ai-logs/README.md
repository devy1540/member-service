# AI 세션 기록

사용 도구: **Codex**. 개발 세션 `01a1c44e-6036-7f30-81ce-3f42ce6fbac7`의 수집 기록을 내보냅니다. 다른 채팅의 대화는 포함하지 않습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `session.jsonl` | 지정 세션에서 수집한 전체 이벤트. 프롬프트·응답·명령·도구·파일 수정 기록과 메타데이터 포함 |
| `prompts.jsonl` | 입력 프롬프트 |
| `responses.jsonl` | AI의 중간·최종 응답 |
| `commands.jsonl` | 실행 명령, 작업 폴더, 종료 코드와 수집된 출력 |
| `tools.jsonl` | 명령 이외의 도구 호출 및 결과 |
| `files.jsonl` | 파일 생성·수정·삭제·이름 변경, 전후 메타데이터와 수집된 텍스트 diff |
| `collector.jsonl` | 수집기 시작·종료·오류 기록 |
| `manifest.json` | 내보낸 시각, 종류별 이벤트 수, 파일 SHA-256, 마스킹 내역 |

각 종류의 이벤트는 수집 순서대로 모두 포함합니다. `session.jsonl`과 항목별 파일에는 같은 대화가 중복 표현될 수 있습니다. 원래 이벤트의 시각과 순서는 유지하며 일부 대화나 명령만 선택하지 않습니다.

## 마스킹과 원본 구분

이 파일들은 **마스킹된 전체 기록이며, 무편집 원본이 아닙니다.** 수집 로그에 이미 적용된 회사명 표기 마스킹을 유지하고, 내보낼 때 로컬 계정 경로·계정명·이메일과 알려진 인증정보 형식을 `***`로 가립니다. 예제 이메일도 같은 규칙으로 마스킹될 수 있습니다. 추가 문자열은 `--redact-text`로 지정할 수 있습니다.

암호화된 내부 페이로드와 이미지 등의 data URI는 데이터 손상을 막기 위해 그대로 보존합니다. 자동 마스킹이 모든 민감 정보를 식별한다고 보장하지 않으므로 외부 제출 전에 확인해야 합니다. 이 프로그램은 외부 전송을 하지 않습니다.

Codex가 저장한 실제 대화 원본은 변경하지 않습니다. 제출 기록을 무편집 원본으로 설명하지 않으며, 회사명 마스킹이 제출처의 허용 범위에 드는지는 별도로 확인해야 합니다.

## 자동 수집과 갱신

[수집 프로그램](../session-logging/logger.py), [설정](../session-logging/config.json), [자동 실행 설정](../session-logging/launch-agent.plist), [사용법](../session-logging/README.md)을 저장소에 포함합니다. 실행 중 수집기는 원래 위치에 계속 기록하며, 제출본은 자동 갱신되지 않습니다.

저장소 루트에서 다음 명령으로 제출본을 갱신하고 검증합니다.

```sh
python3 session-logging/export_submission.py
python3 session-logging/export_submission.py --check
```

내보내기는 SQLite 읽기 전용 트랜잭션 하나에서 모든 종류를 같은 시점 기준으로 읽습니다. `ai-logs/`는 파일 감시에서 제외하여 제출본 자체가 다시 수집되는 순환을 방지합니다.

운영용 SQLite 인덱스와 파일 내용 스냅샷 캐시는 제출본에 복제하지 않습니다. 대화·명령·파일 이벤트 및 수집된 diff는 빠짐없이 포함합니다. `files.jsonl`의 과거 스냅샷 경로는 원래 로컬 수집 환경을 가리키므로 이 제출 폴더에서는 열리지 않을 수 있습니다. 명령 출력 잘림과 파일 감시의 한계는 수집기 문서에 명시합니다.
